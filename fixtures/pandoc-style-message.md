## 一、求和求导

前向是 $\bm{y} = \sum_i \bm{y}^{(i)}$，对"求和"求导就是**广播**：

$$\frac{\partial}{\partial \bm{y}^{(i)}}\Bigl(\sum_k \bm{y}^{(k)}\Bigr) = 1
\quad\Longrightarrow\quad
\bm{dy}^{(i)} = \bm{dy}\quad\text{（每台设备拿到完全相同的 } \bm{dy}\text{，没有 } \frac{1}{N_{\mathrm{TP}}}\text{ 因子）}$$

然后各 rank 在**自己的分片**上照常反传：

$$\bm{dz}^{(i)} = \bm{dy}\,\bm{W}_3^{(i)\top},\qquad
\bm{dx}_2^{(i)} = \bm{dz}^{(i)} * f(\bm{x}_1^{(i)}),\qquad
\bm{dx}_1^{(i)} = \bm{dz}^{(i)} * f'(\bm{x}_1^{(i)}) * \bm{x}_2^{(i)}$$
